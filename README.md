# make-bilingual-study-pdf

这个仓库维护一个可独立安装的 Codex Skill，用于把英文作业、论文和讲义制作成
英文在前、简体中文紧随其后的学习版文档，并保留可审计的完整性证据。

唯一的可安装负载位于
[`skills/make-bilingual-study-pdf/`](skills/make-bilingual-study-pdf/)。安装、依赖和
使用说明见该目录的
[`README.md`](skills/make-bilingual-study-pdf/README.md)。仓库根目录不再作为 Skill
安装路径。

开发与发布门禁见 [`docs/development.md`](docs/development.md)。V2.3 的历史验收证据
保留在 [`.github/V2.3_ACCEPTANCE.md`](.github/V2.3_ACCEPTANCE.md)，不参与后续版本
元数据校验。
